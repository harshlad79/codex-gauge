# 요구사항 및 범위

- 기본 화면: Codex, 플랜, Session, Weekly, 리셋까지 남은 시간, 상대 Updated 표시.
- 호버: 절대 Fetch 시각과 상세 정보 표시.
- 오류: 배경 붉은색, 최신 오류 최대 3개, 정상 복귀 시 오류 영역 축소.
- Session 그래프: 현재 Session 리셋 윈도우 5시간, 30분 단위 10칸.
- Session 막대는 각 30분 동안 증가한 사용량. 누적률이 아님.
- Weekly 그래프: 현재 Weekly 리셋 윈도우 7일, 12시간 단위 14칸.
- Weekly 막대는 누적률. 이전 모든 층과 그 경계를 뒤의 막대에도 보존.
- 각각 과거 사용 구간 경향(점선)과 이번 reset 경향(금색 직선), 100% 도달 시각 및 reset 대비 +/- 여유 표시.
- 두 그래프 모두 왼쪽은 윈도우 시작, 오른쪽은 리셋 예정 시각.
- 100%·50% 기준선 표시. 0% 글자는 생략.
- 실제 데이터와 아직 도달하지 않은 미래 칸을 구분.
- 그래프 점 호버 시 해당 시점의 사용률과 시각 표시.
- 사용 위험은 주황색, 조회 실패만 붉은색. 실패 시 마지막 성공 값·시각 유지.
- 현재 진행 중 칸도 매분 갱신. 성공 스냅샷은 최대 60일 보관.

비범위: `auth.json` 자체 보관, access token 보관, 별도 트레이 앱 구현.
