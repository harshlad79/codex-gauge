# 그래프 규격

## Session

```text
시간축: 현재 Session 시작 → Session reset 예정
범위: 5h
칸: 10개 × 30m
값: 각 30분 구간의 사용 증가분 (전체 5시간 한도 대비 %p)
```

## Weekly

```text
시간축: 현재 Weekly 시작 → Weekly reset 예정
범위: 7d
칸: 14개 × 12h
값: 0~100% 누적 사용률
```

Weekly 막대 전체 높이는 해당 시점의 누적 사용률이다. 예를 들어 10 → 25 → 31%면 층은 `[10]`, `[10,15]`, `[10,15,6]`. 세 번째 막대에도 10%, 25% 높이의 과거 경계가 모두 남는다. 선은 각 막대 폭 안에서만 그린다.

미래 bucket은 빈칸이다. 미래 bucket 때문에 마지막 실제 점이 0%로 떨어지는 선을 그리지 않는다.

## 공통 좌표·관측 규칙

- Y축 고정 0~100%. 글자는 100%, 50%만 표시하고 기준선 중앙에 정렬.
- 진행 중 칸은 매 폴링 최신 관측까지 표시. 미래·관측 없는 칸은 빈칸.
- Session은 구간 시작 기준 관측이 없거나 5분 이상 비었으면 증가분을 미상으로 표시. 실제 누적률은 호버로 확인 가능.
- 실제 0%가 reset 시작 후 5분 안에 관측된 경우 첫 구간 기준으로 사용. reset 값 변경만으로 0%를 만들지 않는다.
- 작은 양수 Session 막대는 최소 1px로 표시하며, 정확한 값은 호버에서 확인. Y축 자체를 자동 확대하지 않는다.
- Weekly 미상 구간의 누적치는 회색 층으로 구분. 같은 reset에서 값이 감소하면 보정 데이터로 취급하고 이전 층을 잘못 유지하지 않는다.
- reset 시각의 60초 이내 흔들림은 같은 창으로 묶되 연쇄적으로 무한 병합하지 않는다. 현재 창 끝은 최신 응답을 기준으로 한다.

## 두 예측선

1. History: 최근 60일 중 사용이 관측된 각 reset의 기울기를 구하고 중앙값 사용. 분당 최신 표본 하나, reset별 동일 가중치. 실제 사용 없는 0% 대기 창 제외. 표본 1개인 창은 기울기를 임의 추정하지 않음.
2. This reset: 이번 reset 관측들만 선형 회귀한 기울기. 두 시점 이상, 관측 간격 60초 이상 필요.

두 직선은 마지막 실제 누적점에 맞춰 100% 또는 reset까지 연장한다. History는 청보라 점선, 현재는 금색 실선. 같은 기울기면 겹칠 수 있으며 구분을 위해 값 자체를 변조하지 않는다. `100% 예상 시각 - reset 시각`이 음수면 리셋 전에 고갈, 양수면 여유. 그래프 밖의 도달 시각도 아래 문구에 표시한다. 예측은 보장이 아니다.

계산 가능하지 않으면 Collecting trend. 구간을 지나면 이전 예측을 계속 표시하지 않고 reset 데이터 대기 상태로 전환한다.
