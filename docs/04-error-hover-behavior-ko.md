# 오류·호버 동작

정상:

- 기본 배경색.
- 빈 `Errors:` 영역 숨김.
- 본문은 `Updated at 30s ago`, Updated 툴팁은 `Fetched at YYYY-MM-DD HH:MM:SS`.
- 스킨 호버 시 같은 스킨 내부 확장 패널: Session 위, Weekly 아래. 아래 그래프로 이동해도 창 안에 있는 동안 유지.
- Updated 클릭으로 즉시 조회. 인증 파일명 등 내부 구현 문구는 표시하지 않음.

오류:

- 오류 배경색.
- 최신 오류부터 최대 3개.
- 오류 영역만큼 패널 높이 증가.
- 다음 성공 조회 때 정상 배경과 원래 높이로 복귀.
- 성공 전까지 마지막 성공 사용량·Fetched 시각은 그대로. 성공 기록 없는 초기 실패는 0%가 아닌 `--`.
- 오류 상세 원문/토큰은 저장하지 않고 안전한 오류 분류와 UTC 발생 시각만 최근 3개 저장.

그래프 호버는 관측된 칸만 활성화한다. 하단 readout에 구간 시각과 누적률, Session은 구간 증가분도 표시. 미래 칸 hitbox는 숨긴다.

위험 경고는 전체 주황 배경 + 하단 메시지. Session은 80% 사용 또는 예측 reset 여유 1시간 이하, Weekly는 90% 또는 1일 이하. 둘 다 해당하면 Session 우선. 붉은 배경은 조회 실패에만 사용한다.

기본 설계 크기 320×150, 상세 패널 +430px, 경고 +38px, 오류는 최대 3×34+16px. 실제 창은 외곽선 때문에 폭/높이가 각 1px 더 클 수 있다. 숨긴 미터의 위치도 축소 크기에 영향을 주지 않게 정리한다.
